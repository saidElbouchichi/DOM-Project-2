# DOM Project 2 — Changeur de couleurs interactif (GOMYCODE)

Page web simple : un titre, une boîte colorée et un bouton.
Au clic sur le bouton, la fonction `getRandomColor()` génère un code couleur hexadécimal aléatoire, qui devient la couleur de fond de la boîte (`colorBox`). Le code de la couleur s'affiche sous la boîte.

- `index.html` : structure de la page
- `style.css` : style de base
- `script.js` : logique (DOM, `getRandomColor()`, écouteur de clic)

Ouvrir `index.html` dans le navigateur.
